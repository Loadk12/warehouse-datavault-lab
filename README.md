# Хранилища данных. Лабораторная работа по Git и GitHub

Исходный код лабораторной работы №2. Вариант 8 — обработка заказов в службе быта.

В каталоге `sql` находятся схемы 3НФ и Data Vault, синтетические данные, загрузка снимков, представления и проверки. `run_lab.py` выполняет сценарий через `psql`. На синтетических данных проверены история статусов, повторная загрузка и сверка сумм с 3НФ.

Для запуска создайте пустую базу PostgreSQL, установите клиент `psql` и задайте параметры подключения `PGHOST`, `PGPORT`, `PGUSER`, `PGDATABASE`. Для аутентификации используйте обычные средства PostgreSQL, например `.pgpass`. Затем выполните `python run_lab.py` из корня репозитория. Для полного повторного прогона используйте новую пустую базу.

Историю проекта можно посмотреть командой `git log --oneline`.
